# 大款桌宠

Windows 桌面单宠。应用使用 Electron、React 和 TypeScript，透明窗口会覆盖已连接显示器的区域，宠物空白处点击穿透到桌面。

项目需求、架构与需求变更记录集中在 [`docs/`](docs/)；Codex 项目指令入口保留在根目录 [`AGENTS.md`](AGENTS.md)。

0.4.0：新增“大款餐厅”，点击面板第二行的“餐厅”进入。手动切肉、炸薯条、卷饼、制作饮料，按小猫顾客的订单出餐并点击收款；营业收入与原有金币共用。每轮迎客 3 分钟，可升级 9 类设备、雇用猫咪员工、解锁烤饼/套餐和自动收款。餐厅内提供“开店手册”；切页或失焦暂停营业，重启后可继续原来的营业进度。开发位于 `feature/dakuan-restaurant`，`main` 保留 0.3.3 基线。

0.3.3：修复亲密度卡在 11 级、精简重复页面标题、商店点击服装可看大图；金鱼果与奶果可合成金鱼奶香罐头。主页底部的“设置”可调节音量、静音、退出和输入兑换码。“大款”礼包每份存档限一次，奖励 200 金币、10 个化肥、花园园丁套装。升级读取旧档时保留资产并补齐新增字段，迁移前另存有效备份。

## 开发

需要 Node.js 20.19 或更新版本。

```powershell
pnpm install
pnpm dev
```

## 构建

```powershell
pnpm build
```

## 制作 Windows 发布包

```powershell
pnpm dist:win
```

完成后会生成 Windows x64 安装版、x64 便携版和 ARM64 便携版。普通 Intel/AMD 电脑使用 x64 版本；免安装时使用兼容便携版。Windows on ARM 使用 ARM64 便携版。安装版按当前用户安装，不需要管理员权限；所有版本都内置运行环境，无需安装 Node.js。产物版本号以 `package.json` 为准。

应用运行时固定使用 Electron 44.7.2，并自动关闭 GPU 硬件加速；窗口会在加载完成或超时后显示，避免部分显卡驱动下窗口一直隐藏。若界面仍无法显示，日志保存在 `%APPDATA%\DakuanDesktopPet\logs\startup.log`。应用支持 64 位 Windows 10 及以上；32 位 Windows 和 Windows 7/8/8.1 不受当前 Electron 版本支持。便携版没有代码签名证书，Windows SmartScreen 可能仍会显示首次运行提示。

宠物状态保存在 `%APPDATA%\DakuanDesktopPet\pet-state.json`，覆盖更新不会清除已有记录；手动迁移到另一台电脑时需要一并复制该存档。

点击大款会让它停在原地并打开照料面板，面板打开期间不再漫游；照料动作仍会播放。按 Esc 可以退出桌宠。当前便携包没有代码签名证书，Windows SmartScreen 可能会显示首次运行提示。若确认文件来自你本人，可以在提示中选择“更多信息”后运行。

大款是根据照片制作的圆滚滚暹罗猫 2D 形象，透明背景动作图集有 4 列、8 种动作，每种动作含四帧动画。面板可切换像素显示与平滑插画显示。大款会在桌面上走动、偶尔跑步，停下来后随机触发待机动作；到达屏幕边缘会转向。点击大款后停止漫游，打开面板；照料时继续播放对应动作。

衣服仓库与穿搭商店都是面板标签页，商店不再通过弹出浮层打开。右上角图钉按钮可切换桌宠置顶状态，设置会保存；系统托盘菜单也能切换。当前包含完整穿搭动作图集及成就服装；切换穿搭时整套动作图同步更换。图集处理会逐帧分离角色、统一待机宽度和脚底锚点，限制最大帧幅，并在每格四周留透明边距。重新打包图集时使用 Windows PowerShell 5.1 运行 `scripts/pack-outfit-atlas.ps1`。装扮商店每 5 小时随机展示最多 4 套未拥有穿搭。厨房第 3、4、5、6 口锅分别在体重达到 20 斤、100 斤、500 斤和 2 吨时解锁。菜园铲除使用对准铲尖的系统光标，点击作物即可铲除。

## 全服饰解锁测试版

运行 `pnpm dist:test` 会在 `release/test` 生成独立的 Windows x64 便携版。测试版直接拥有全部穿搭，并使用单独的应用标识和 `%APPDATA%\DakuanDesktopPet-Test` 存档目录，不会改动正式版存档。

状态文件保存在 Electron 的用户数据目录 `pet-state.json` 中。状态值按现实时间缓慢变化；暂停时不衰减。厨房包含最多六口逐步解锁的锅、粮柜和食谱收集；给大款展示并提供的都是猫咪食物。
